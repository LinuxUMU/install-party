Buenos días linuxeros,

Entre algunos estudiantes, estamos montando una nueva iniciativa de software
libre en la Facultad: LinuxUMU.

Vamos a formar primero un club dentro de la Facultad de Informática, y cuando
haya masa crítica, una asociación universitaria.

Las actividades de este grupo serán algo parecidas a las de la antigua Caldum,
talleres, charlas, quedadas, etc.

La primera actividad es esta misma semana, para anunciar la iniciativa de paso.
Se trata de una Linux Install Party para que los estudiantes de nuevo ingreso
reciban ayuda para instalar Linux en sus portatiles para empezar bien el curso.

Se realizará el Viernes 25 de Septiembre durante todo el día en la 0.01 de la FIUM.

Quedais invitados a venir si os interesa ayudar, y informaros sobre esta iniciativa
estudiantil.
